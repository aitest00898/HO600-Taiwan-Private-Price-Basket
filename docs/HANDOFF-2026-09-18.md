# 19. Evidence Gate

任何要正式升級為 Exact 的 concept，必須滿足：

| RequirementRule |                                              |
| --------------- | -------------------------------------------- |
| Baseline        | Exact-2020                                   |
| Current         | Exact-2026                                   |
| Price           | normal / list / base / original normal price |
| Identity        | 可識別商品／服務                                     |
| Spec            | 可比較                                          |
| Channel         | 可比較                                          |
| Geography       | 不可錯地區／門市                                     |
| Source          | URL 可追溯                                      |
| Dating          | 年份／日期可驗證                                     |
| Promotion       | 不得採促銷 effective price                        |

Comparability A 優先。

B 只有在 linkage 明確時才能收。

禁止：

BOGO
coupon effective price
member-only effective price
delivery markup
wrong branch
wrong region
wrong package generation
2019/2021 冒充 2020。
