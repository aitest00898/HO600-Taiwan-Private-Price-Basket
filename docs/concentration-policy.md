# Concentration Policy

Reference caps for **new admissions**:

| Surface | Reference cap |
|---|---:|
| Brand / merchant | ≤ 8 |
| Corporate group | ≤ 16 |
| Brand × subcategory | ≤ 5 |
| Same price schedule | ≤ 6 |
| Product family | ≤ 2 variants |
| Top 5 brands | ≤ 40 |
| Top 10 brands | ≤ 60 |
| Same historical source | ≤ 6 concepts |

Legacy valid concepts are not retroactively deleted solely because a cap is exceeded.

Policy for legacy overage: **KEEP LEGACY / FREEZE NEW**.

Current Batch-8 freezes include IKEA total admissions, IKEA×home-storage, the GoShare product family, and the reused THSR 2020 historical source at their respective caps.
